Project 3: Membership Inference and Early Stopping

Goal: infer whether a sample was used to train a target model, using its predicted class probabilities and known task label. Membership labels (member/nonmember) differ from task labels (digits 0-9).
Dataset: public scikit-learn Digits, 8x8 images, 64 features, ten classes. A CSV and source metadata are included for inspection. Use the supplied CSV as your input; implement the training and attack pipeline yourself.
Deduplicate pixels, then create disjoint stratified pools: target train 100, target validation 100, target test 100, shadow pool 1200. Split the shadow pool into 900 attack-training and 300 independent attack-calibration examples. Fit preprocessing only on each model's own training set.
Target model: MLP hidden layers (64,32); compare fixed 600 epochs against validation-loss early stopping with patience 10. Train three shadow models to generate member/nonmember attack training records. Use an independent calibration shadow for attack validation.
Required attacks: negative cross-entropy loss score and a shadow-trained logistic classifier. Possible attack features include true-label probability, loss, entropy, confidence, correctness and task label.
Choose attack models/thresholds using shadow validation only. Freeze them before target evaluation. Attack Test uses 100 target-training members and 100 target-test nonmembers. Target validation is excluded because it participates in model selection.
Metrics: ROC-AUC, TPR at FPR <= 5%, target training/test accuracy, and variability across seeds 42/43/44. AUC 0.5 is random guessing. The low-FPR estimate has uncertainty because there are only 100 nonmembers; early stopping need not improve every metric.

Environment:
conda env create -f environment.yml
conda activate privacy_projects
Implement your own target training, shadow models, attacks, evaluation and defense. Run seeds 42, 43 and 44 with settings frozen before target attack-Test evaluation. Report means and variability rather than selecting the best seed.
Submission: source code, frozen settings, metrics, ROC curves, task learning curves and a report explaining attack performance and defense tradeoffs.
Open directions: attack features, per-class attacks, model size, regularization, training duration, alternative thresholds and uncertainty analysis. Compare under the same data protocol and do not tune against target attack-Test labels.
